# 化學教學互動教材庫

本倉庫用於整理課堂教學所使用的數位教材，內容包括簡報、互動式 HTML 教材、模擬活動頁面及相關教學資源。

## 內容簡介

本教材庫主要按章節分類，方便教師授課時快速取用，也方便學生按主題瀏覽、下載及使用。部分內容由為 HTML 頁面，適合在電腦或平板瀏覽器中直接開啟。

## 資料結構建議

可按章節建立資料夾，例如：

- `chapter-01/`：第一章教材
- `chapter-02/`：第二章教材
- `chapter-03/`：第三章教材

每個章節內可包含：

- `index.html`：章節入口頁
- `slides.html`：教學簡報頁
- `activity.html`：互動活動或模擬頁
- 圖片、樣式表、JavaScript 等支援檔案

## 使用方式

- 學生可透過 GitHub Pages 或指定連結進入各章節教材。
- 如需離線使用，可下載整個章節資料夾後再開啟 `index.html`。

## 備註

為確保教材能正常顯示，建議保留原有資料夾結構，避免只單獨移動某一個 HTML 檔案而遺漏其相依資源。
