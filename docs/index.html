使用方式

教師端

  • 把教材放進對應章節資料夾。
  • 更新後 push 到 GitHub repository。
  • GitHub Pages 會自動更新靜態網站內容。[web:27][web:173]
  • 上課時可直接打開章節頁作投影展示。

學生端

  • 直接用瀏覽器開啟網站。
  • 按章節進入對應教材頁。
  • 可閱讀說明、觀看簡報、操作互動頁。
  • 之後可再加上提問表單或 FAQ 頁面。

網站結構建議

GitHub Pages 很適合托管靜態網站；常見做法是將網站檔案整理在 repository 的根目錄或 docs/ 資料夾，再於 Pages 設定中選擇該來源資料夾發布。[web:27][web:40]

docs/
├─ index.html
├─ chapter01/
│  └─ index.html
├─ chapter07/
│  ├─ index.html
│  ├─ slides.html
│  ├─ activity.html
│  └─ quiz.html
└─ assets/
   ├─ css/
   ├─ js/
   └─ img/

assets 資料夾

用來集中放樣式、腳本、圖片等支援資源，方便不同頁面共用與維護。靜態網站通常由 HTML、CSS 與 JavaScript 組成。[web:161][web:168]

首頁 index.html

首頁是整個網站的導覽中心，適合放章節卡片、網站說明、更新公告與學生使用指引。GitHub Pages 會尋找 index.html 等作為入口頁。[web:27]
