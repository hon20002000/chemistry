Lesson-style Home Page

用左側導航管理整個化學教材站

這個首頁參考 lesson-template 的核心思路：左側放課程導航與章節入口，右側放首頁說明、重點章節、更新資訊與教材使用方式。這類 sidebar 版型很適合 lesson / workshop / documentation 網站，也適合你的 chapter 式教材站。[web:315]

查看全部章節 查看已建立章節

首頁定位

首頁不需要承載所有內容，而是作為整個網站的總入口。每章各自有自己的 index.html，首頁只需負責清楚導航，這正符合 lesson-template 那種以 sidebar 提供結構化導覽的設計方向。[web:315]

  • 左側：固定導航、章節入口、快速跳轉。
  • 右側：首頁介紹、已建立章節、使用說明。
  • 每章：獨立 index.html，再連到 slides、activity、quiz。

維護建議

Learn-Static 的 lesson-template 是以 sidebar 導航作為網站核心，並強調 lesson / workshop / documentation 類型內容的清楚分段與結構化頁面。[web:315]

  • 首頁維持穩定，不需要每次加入很多教學內容。
  • 每新增一個 chapter，只需新建資料夾與章節首頁，再補一個連結。
  • 若之後章節變多，可把左側導航再拆成「上學期 / 下學期」或「基礎 / 鍵結 / 計算 / 平衡」四組。

目前已按你現有資料夾名稱接好 Chapter 05、07、08；之後只要持續補相同命名規則即可。
