# 概念重點

## 1. 金屬鍵

金屬內，金屬離子被可自由移動的離域電子包圍。金屬鍵是離域電子與金屬離子之間的靜電引力。[file:344]

## 2. 離子的形成

當原子失去電子，就會形成陽離子；當原子獲得電子，就會形成陰離子。生成離子時，改變的是電子數目，不是質子數目。[file:344]

## 3. 離子鍵

離子鍵是帶相反電荷的離子之間的靜電引力。鈉與氯反應時，電子由鈉轉移至氯，生成 Na+ 和 Cl-，再進一步形成離子化合物。[file:344]

## 4. 常見迷思

- 失去電子不是變成負電，而是變成正電。
- 原子變成離子後，元素種類沒有改變。
- 離子化合物不是一個個獨立小分子，而是大量離子規則排列形成結構。[file:344]
