Teacher Editable Chapter Page

第七章｜可插入 Markdown 與 HTML 的章節頁

這個版本不是只給學生看，也同時是給你維護內容用的章節模板。頁面保留固定版面，但每個教學區塊都明確標示哪些地方適合用 Markdown 寫概念、題目與提示，哪些地方適合用 HTML 放互動題、答案展開區或小動畫。[web:348][web:365]

對你這類化學教材站來說，最好的做法是把說明文字與題幹交給 Markdown 管理，把互動展示與概念動畫交給 HTML/CSS/JavaScript 管理，這樣修改內容時最方便，也不容易破壞版面。[web:349][web:356][web:367][web:370]

內容插槽總覽

下面這些插槽名稱可以直接沿用到你之後所有章節。你只要維持相同命名，之後每章都會很好維護。

Markdown md-intro

放本章導言、學習目標、課前提問、課後重點整理。最適合純文字與條列內容。[web:349][web:357]

在這裡貼上 Markdown 內容，例如章節簡介、概念重點、學習提示。
Markdown md-concept-notes

放概念說明、例子、錯誤觀念提醒、比較表。適合快速編輯與增補內容。[web:349][web:348]

例如：離子鍵定義、陽離子與陰離子比較、金屬鍵 vs 離子鍵。
HTML html-quick-check

放題目卡、<details> 答案區、配對題、選擇題。這類區塊需要較清楚的互動結構。[web:347][web:356]

在這裡貼上 HTML 題目卡，例如 details/summary、按鈕、選項區。
HTML html-concept-demo

放科學概念小動畫、粒子移動示意、Rutherford scattering、電子轉移、離子遷移等。[web:367][web:370]

在這裡貼上 HTML/CSS/JS 小元件，例如一個動畫容器和播放按鈕。
Markdown md-review

放延遲複習題、回家作業、考前回顧清單。這類內容常常改動，最適合 Markdown。[web:329][web:332]

例如：三天後再做的 5 題回顧題、考前複習 checklist。
HTML html-extra-media

放圖片、iframe、SVG 圖解、互動圖卡。當內容需要特別排版時，優先用 HTML。[web:365][web:370]

例如：內嵌圖片、SVG 示意圖、YouTube、互動卡片。

題目區設計

如果你日後最常做的事情是新增題目，題目區最好分成兩層：題幹可以用 Markdown 產出，但互動包裝建議用 HTML。[web:349][web:356]

名稱：md-quick-questions

用途：題幹草稿、開放式問題、回顧題、工作紙提示。

例如：請解釋離子鍵的形成過程。
名稱：html-quiz-cards

用途：選擇題卡、配對題、答案展開區、即時檢查題。

例如：details/summary 題目卡，或按鈕式選項題。
名稱：html-misconception-check

用途：找錯處題、常見錯誤題、真假判斷題。

例如：讓學生判斷「生成離子後質子數改變」是否正確。
HTML 題目模板範例 
<section id="html-quiz-cards">
  <details>
    <summary>題目 1：鈉原子生成鈉離子時失去多少個電子？</summary>
    <p>答案：1 個。因為鈉最外層有 1 個電子，失去後形成 Na+。</p>
  </details>

  <details>
    <summary>題目 2：離子鍵的本質是甚麼？</summary>
    <p>答案：帶相反電荷離子之間的靜電引力。</p>
  </details>
</section>

動畫模組

像盧瑟福散射實驗、電子轉移、離子遷移這些內容，不建議用純 Markdown；因為它們需要運動、顯示切換或互動控制，應使用 HTML/CSS/JavaScript 模組。[web:367][web:370]

建議名稱
  • html-rutherford-demo
  • html-electron-transfer-demo
  • html-ion-migration-demo
  • html-particle-model-demo
適合放甚麼
  • Canvas 動畫或 div 動畫
  • 播放 / 暫停 / 重播按鈕
  • 圖解切換與重點標示
  • 學生點擊後顯示解釋
HTML 動畫模組骨架範例 
<section id="html-rutherford-demo" class="concept-demo">
  <h4>盧瑟福散射實驗</h4>
  <div class="animation-stage"></div>
  <button>播放動畫</button>
  <p>大部分 α 粒子直線穿過；少數偏折；極少數反彈。</p>
</section>

命名規則

命名只要固定，以後就很容易維護。最簡單的規則就是：格式-用途-主題。

Markdown 區塊

md-intro、md-ion-formation、md-review、md-misconceptions

HTML 區塊

html-quiz-cards、html-ion-demo、html-rutherford-demo、html-extra-media

避免命名

不要用 box1、test2、new-div 這類名稱，日後會很難找。

你應該怎樣修改

最推薦的實際工作流程如下。

情況 1：只是改解說文字

改 md-intro、md-concept-notes、md-review 這些 Markdown 區塊即可。

情況 2：新增一題

若只是文字題，可加到 md-quick-questions；若要有答案展開或題卡，則加到 html-quiz-cards。

情況 3：加入概念動畫

在 html-rutherford-demo 或其他 html-*-demo 區塊新增 HTML/CSS/JS 模組。

情況 4：加入圖片或圖解

使用 html-extra-media，因為圖片比例、說明文字和排版通常都需要 HTML 控制。
